# Nested Outline Numbering

Obsidian plugin ที่รวมระบบเลขลำดับชั้นไว้ในตัวเดียว ทำงานได้ทั้ง 2 แบบ

- **เลขข้อความล้วน** ชั้น 1-3 ใช้ `1.` / `1.1.` / `1.1.1.` ชั้น 4 ลงไปเริ่มนับใหม่และปิดด้วยวงเล็บ `1)` / `1.1)`
- **เลขใน Markdown heading** `# 1 บทนำ` / `## 1.1 ขอบเขต` / `### 1.1.1 รายละเอียด` / `#### 1) ข้อ`

ทั้งสองแบบเลขถูกเขียนลงไฟล์เป็นตัวอักษรจริง ก๊อปไปแอปอื่นได้เลขไปด้วย และถูก renumber ให้เองเมื่อขยับ level หรือย้ายตำแหน่ง

## ปุ่มที่ใช้

| ปุ่ม | บนบรรทัดเลขข้อความ | บนบรรทัด heading |
|---|---|---|
| `Tab` | ย่อลงหนึ่งชั้น พร้อมกิ่งลูกทั้งหมด | เพิ่ม level ของ `#` แล้ว renumber |
| `Shift + Tab` | ถอยกลับหนึ่งชั้น (ชั้นบนสุดไม่ทำอะไร) | ลด level ของ `#` แล้ว renumber |
| `Enter` | ขึ้นรายการใหม่ระดับเดียวกัน | ปล่อยให้ Obsidian ทำงานปกติ |
| `Alt + ↑ / ↓` | สลับกับรายการข้างเคียงที่ระดับเดียวกัน | สลับทั้ง section กับ heading ข้างเคียงระดับเดียวกัน |

- การย้ายด้วย `Alt + ↑ / ↓` **อยู่ระดับเดียวกันเท่านั้น** ไม่กระโดดข้าม level และ cursor จะตามไปอยู่บนบรรทัดที่ย้าย
- ปุ่มทั้งหมดทำงานเฉพาะบรรทัดที่ plugin รู้จัก บรรทัดอื่น `Tab` ยังเป็น indent ปกติของ Obsidian

## รูปแบบที่ plugin รู้จัก

**เลขข้อความล้วน** ชั้น 1-3 ปิดท้ายด้วยจุด ชั้น 4 ลงไปปิดท้ายด้วยวงเล็บ ย่อ 2 เครื่องหมายวรรคต่อชั้น

```
^[ \t]*(\d+(?:\.\d+)*)[.)][ \t]+
```

```text
1. บทนำ
  1.1. ขอบเขต
    1.1.1. รายละเอียด
      1) ข้อแรก
        1.1) ข้อย่อยของข้อแรก
      2) ข้อสอง
2. สรุป
```

ระดับ (level) ถูกอ่านจาก indent ไม่ได้อ่านจากตัวเลข ดังนั้นย่อเข้าออกแล้วเลขจะเปลี่ยนรูปให้เอง เช่น `1.1.1.` ย่อลงมาเป็นชั้น 4 จะกลายเป็น `1)` และ `1)` ถอยขึ้นไปเป็นชั้น 3 จะกลายเป็น `1.1.2.`

หลังกด `Tab` หรือ `Shift + Tab` cursor จะคงตำแหน่งเดิม**ในเนื้อความ** ไม่ไปค้างกลางตัวเลข เช่น `2. ` กลายเป็น `  1.1. |` ไม่ใช่ `  1.1|. `

`1.1` ที่ไม่มีจุดปิดท้ายจะไม่ถูกจับ เพราะ `1.1.` ไม่ใช่ Markdown list marker มันจึงเป็นข้อความธรรมดา นี่คือเหตุผลที่ก๊อปไปที่อื่นแล้วเลขติดไปด้วย

**Heading** `#` 1 ถึง 6 ตัว ตามด้วยช่องว่าง ชั้น 1-3 ใช้เลขไม่มีจุดปิดท้าย (`## 1.1 ขอบเขต`) ชั้น 4 ลงไปปิดด้วยวงเล็บ (`#### 1) ข้อ`)

## การ renumber อัตโนมัติของ heading

`Tab` / `Shift + Tab` / `Alt + ↑ ↓` บน heading จะ renumber ให้เอง **ถ้าโน้ตนั้นอยู่ในโหมดมีเลขแล้ว** (คือมี heading อย่างน้อยหนึ่งบรรทัดที่มีเลขนำหน้า)

โน้ตที่ยังไม่มีเลขจะไม่ถูกใส่เลขให้อัตโนมัติ ต้องเปิดโหมดด้วยคำสั่ง `Number headings in note` ครั้งหนึ่งก่อน กันไม่ให้โน้ตที่ไม่อยากได้เลขโดนใส่โดยไม่ตั้งใจ

## คำสั่งใน Command Palette

| คำสั่ง | ทำอะไร |
|---|---|
| `Number headings in note` | ใส่เลข `1` / `1.1` / `1.1.1` ให้ทุก heading ในโน้ต |
| `Remove heading numbers` | ลบเลขออกจากทุก heading |
| `Renumber nested block` | เรียงเลขข้อความในบล็อกใหม่ตามระดับ indent จริง |
| `Insert nested numbering` | เปลี่ยน outline ที่ย่อด้วย space ให้เป็นเลข |
| `Remove nested numbering` | ลบเลขข้อความออก เก็บ indent ไว้ |

ทุกคำสั่งใช้ transaction เดียว กด `Ctrl + Z` ครั้งเดียวคืนค่าทั้งหมด

## ติดตั้ง

คัดลอก 3 ไฟล์ไปที่ `<vault>/.obsidian/plugins/nested-outline-numbering/`

```
main.js
manifest.json
styles.css
```

แล้วเพิ่ม `"nested-outline-numbering"` ลงใน `<vault>/.obsidian/community-plugins.json` หรือเปิดจาก
`Settings → Community plugins` (กด reload ถ้าเพิ่งวางไฟล์)

## ติดตั้งบนเครื่องอื่น

`main.js` เป็นไฟล์เดียวจบ ไม่มี build step และไม่พึ่ง dependency ภายนอก (ใช้แค่ `require("obsidian")` กับ `@codemirror/*` ที่ Obsidian มีให้อยู่แล้ว) จึงคัดลอก 3 ไฟล์ไปวางเครื่องไหนก็ได้

## พัฒนาและทดสอบ

```bash
node test/core.test.js
```

`main.js` แยกส่วน CORE (ตรรกะข้อความล้วน ไม่แตะ Obsidian API) ไว้อีกส่วนหนึ่ง ทำให้รัน unit test ใน Node ได้ โดย test จะ stub `require("obsidian")` กับ `@codemirror/*` ให้เอง

## ข้อจำกัดที่รู้อยู่

- `Tab` / `Shift + Tab` ใช้กับ **บรรทัดที่มี cursor** เท่านั้น ยังไม่รองรับการเลือกหลายบรรทัดพร้อมกัน
- เลขข้อความ: `Tab` ย่อได้เฉพาะเมื่อมีรายการก่อนหน้าที่ระดับเดียวกันอยู่ก่อนแล้ว (ถ้าเป็นลูกคนแรกจะไม่มีอะไรให้ไปเป็นลูกของมัน) ซึ่งตรงกับพฤติกรรมของ Word
- `Alt + ↑ / ↓` ที่ขอบบนหรือล่างของระดับจะไม่ทำอะไร ไม่มีการถอย level ให้ ต้องกด `Tab` / `Shift + Tab` เอง
- heading ที่ข้ามระดับ (H1 แล้วไป H3) เลขชั้นที่ขาดจะถูกเติมเป็น 1 เช่น `1.1.1`
